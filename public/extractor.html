🧩 강하고 알리피드 추출기 — 항상 최신본

이 페이지는 언제나 최신 추출기 1개만 보여줍니다. 여기서 복사해 알리피드 콘솔에 붙여넣으세요. (이 주소를 즐겨찾기 해두세요.)
현재 최신 버전
불러오는 중…
1. 위 [📋 추출기 전체 복사] 클릭 (클립보드에 복사됨)
2. 알리피드 회원(koreaalipeed) 주문 목록 페이지에서 F12 → 콘솔(Console) 탭
3. 콘솔에 Ctrl+V 붙여넣기 → Enter
4. ★시작 시 콘솔 첫 줄에 [추출기 v…] 가 보이는지 확인 — 이 버전과 같아야 최신
5. 선적일은 자동 도출(주문 실제출고요청일) — 수동 입력 없음. 날짜 섞이면 차단되니 알리피드 검색을 한 날짜로 좁혀 실행
📄 코드 미리보기 (복사 버튼 권장 — 직접 선택도 가능)
최신본 경로: /alipeed-extractor-latest.js · 버전이 안 맞으면 새로고침(Ctrl+Shift+R) 후 다시 복사.
